## 🔐 Focus: security and OIDC in Symfony

I built the **OIDC Authorization Code Flow authenticator** (`oidc_login`) for [Symfony 8.2](https://symfony.com/doc/8.2/security/oidc_login.html): sign in with any OpenID Connect provider, secure by default.
